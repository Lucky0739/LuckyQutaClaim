# 秒杀商城常见问题FAQ

## 快速问答

### 关于秒杀活动
**Q: 秒杀活动什么时候开始？**
A: 我们的秒杀活动每天分三个时间段：上午10点、下午3点、晚上8点准时开抢。

**Q: 秒杀商品有数量限制吗？**
A: 是的，秒杀商品数量有限，售完即止。每个用户每种秒杀商品限购1件。

**Q: 秒杀价格会再降吗？**
A: 秒杀价格已经是活动期间的最低价，不会再降。请抓紧时间抢购！

### 关于订单处理
**Q: 下单后多久发货？**
A: 订单支付成功后24小时内商家会安排发货，节假日期间可能顺延。

**Q: 可以修改收货地址吗？**
A: 待发货状态的订单可以联系客服修改地址；已发货的订单无法修改，但可以联系快递公司拦截。

**Q: 订单超时未付款会自动取消吗？**
A: 会的，订单在创建后30分钟内未支付会自动取消。

### 关于支付问题
**Q: 支持哪些支付方式？**
A: 我们支持微信支付、支付宝、银行卡以及平台积分抵扣。

**Q: 支付失败了怎么办？**
A: 请检查：1)网络是否稳定；2)银行卡余额是否充足；3)支付密码是否正确。如持续失败请联系客服。

**Q: 支付成功但订单没显示？**
A: 可能是网络延迟，请稍后刷新页面或联系客服核实处理。

### 关于退换货
**Q: 商品支持无理由退货吗？**
A: 支持7天无理由退货（特殊商品除外），需保持商品完好，不影响二次销售。

**Q: 退货需要自己付运费吗？**
A: 因质量问题退换货由商家承担运费；7天无理由退货由用户承担运费。

**Q: 退款多久能到账？**
A: 退款将在收到商品后的1-3个工作日内原路返回。

### 关于会员积分
**Q: 如何获得积分？**
A: 每消费1元可获得1积分，秒杀商品也按实际支付金额计算积分。

**Q: 积分有什么用？**
A: 积分可在结算时抵扣使用，100积分可抵扣1元。

**Q: 积分会过期吗？**
A: 积分有效期为获得后1年，逾期自动清零，请及时使用。

### 关于配送
**Q: 大概多久能收到货？**
A: 普通快递预计3-7天送达，顺丰速运预计1-3天送达。

**Q: 可以自己选择快递吗？**
A: 一般情况下由系统自动分配快递，不支持指定快递公司。

**Q: 商品少发或错发怎么办？**
A: 请在收到商品后24小时内联系客服，提供相关证据（照片、视频）以便核实处理。
