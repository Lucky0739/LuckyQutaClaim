# 秒杀商城常见问题FAQ

## 快速问答

### 关于账号
**Q: 如何注册和登录？**
A: 您可以使用手机号注册和登录。登录时请确认手机号、密码或验证码正确；如果连续登录失败，请稍后再试或联系人工客服。

**Q: 忘记密码或密码错误怎么办？**
A: 请先确认输入是否正确。如果仍无法登录，可以通过平台提供的验证方式处理，或联系人工客服协助。

**Q: 平台会索要我的密码或验证码吗？**
A: 不会。请不要向任何人透露密码、短信验证码、支付密码等敏感信息。

### 关于余额
**Q: 平台支持余额充值吗？**
A: 支持。登录后可以进入余额页面查询余额并发起充值，充值金额必须大于0。

**Q: 可以用余额支付订单吗？**
A: 可以。余额支付会校验订单状态、订单是否过期以及账户余额是否充足。支付成功后订单会变为已支付。

**Q: 余额支付提示余额不足怎么办？**
A: 请先充值余额，或选择其他当前可用的支付方式。

### 关于秒杀活动
**Q: 秒杀活动什么时候开始？**
A: 秒杀活动时间以活动列表和活动详情页展示为准，请在活动开始后及时参与。

**Q: 秒杀商品有数量限制吗？**
A: 有。系统会校验限购数量、是否重复参与和库存情况，具体以活动规则和页面提示为准。

**Q: 秒杀失败常见原因有哪些？**
A: 常见原因包括活动未开始、活动已结束、库存不足、超过限购数量、重复参与或活动太火爆。请根据页面提示处理。

### 关于订单处理
**Q: 如何下单？**
A: 选择商品规格、购买数量和收货地址后可以创建订单。下单时系统会校验商品、规格、地址、库存和购买数量。

**Q: 下单后多久发货？**
A: 当前系统尚未实现完整物流发货流程。订单支付成功后请关注订单状态，如需了解发货安排请联系人工客服。

**Q: 可以修改收货地址吗？**
A: 下单前可以在收货地址中新增、修改或删除地址。订单创建后如需修改地址，请联系人工客服核实处理。

**Q: 订单超时未付款会自动取消吗？**
A: 待支付订单超过有效时间会变为已过期，过期订单不能继续支付，需要重新下单。

**Q: 订单有哪些状态？**
A: 当前订单状态包括待支付、已支付、已取消和已过期。

### 关于支付问题
**Q: 支持哪些支付方式？**
A: 当前支持支付宝沙箱支付和账户余额支付。暂不承诺微信、银行卡或积分抵扣。

**Q: 支付失败了怎么办？**
A: 请检查订单是否为待支付、是否已过期、网络是否稳定；余额支付还需要检查余额是否充足。如持续失败请联系客服。

**Q: 支付成功但订单没显示？**
A: 可能存在网络或状态同步延迟。请稍后刷新订单列表，或使用订单号查询支付状态；仍异常请联系人工客服。

**Q: 余额扣了但订单没支付成功怎么办？**
A: 系统会尝试自动补偿退回余额。若余额未恢复或订单仍异常，请保留订单号并联系人工客服核实。

### 关于商品和购物车
**Q: 商品详情里能看到哪些信息？**
A: 可以查看商品名称、主图、图片列表、详情内容、价格，以及 SKU 规格、规格图片、库存和销量等信息。

**Q: 商品规格图片怎么看？**
A: 商品详情返回的规格列表中包含规格图片。也可以根据规格 ID 查询单个规格对应的图片。

**Q: 如何加入购物车？**
A: 登录后选择商品、规格和购买数量即可加入购物车。购买数量必须大于0。

**Q: 为什么提示库存不足？**
A: 说明当前商品规格库存不足，建议减少购买数量或选择其他规格。

### 关于收藏
**Q: 可以收藏商品或店铺吗？**
A: 可以。登录后可以收藏商品和店铺，也可以取消收藏并查看我的收藏列表。

**Q: 重复收藏会怎样？**
A: 系统会提示已收藏，请勿重复操作。

### 关于店铺和商家
**Q: 如何开店？**
A: 登录后可上传店铺头像并提交开店申请，申请需要管理员审核。

**Q: 商品为什么需要审核？**
A: 商家新增商品后需要申请上架，管理员审核通过后商品才会正式展示给用户。

### 关于退换货
**Q: 商品支持无理由退货吗？**
A: 当前系统尚未实现完整退换货流程。退换货问题请联系人工客服处理。

**Q: 退货需要自己付运费吗？**
A: 当前系统未维护退货运费规则，请联系人工客服根据订单情况核实。

**Q: 退款多久能到账？**
A: 当前系统未实现自动退款到账流程。请联系人工客服并提供订单号，由客服协助核实。

### 关于配送
**Q: 大概多久能收到货？**
A: 当前系统尚未实现完整物流轨迹功能，具体发货和配送情况请以订单状态或人工客服核实为准。

**Q: 可以自己选择快递吗？**
A: 当前系统暂未提供选择快递公司的功能。

**Q: 商品少发或错发怎么办？**
A: 请联系人工客服，并提供订单号、商品照片或视频等材料，方便核实处理。

### 关于站内通知
**Q: 支付成功会有通知吗？**
A: 支付成功后系统会发送站内通知，您可以在消息列表中查看。

**Q: 管理员消息和普通用户消息有什么区别？**
A: 管理员可以查看管理员相关消息，普通用户只能查看自己的消息。
